What this is. A replay of a scripted shift, not a live model — the agent reasoning was generated ahead of time and checked into run.json, so the page stays a single static file with no key and no backend. The company, the people and every ticket are invented.

What it is actually showing. Not that agents can do work — that part is easy now. It shows the scaffolding that makes them safe to run against real work: a written charter per agent, an autonomy level earned rather than assigned, a human gate on anything that leaves the building, and a log that records who actually pressed send.
